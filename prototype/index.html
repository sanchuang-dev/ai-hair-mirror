    00镜面交互原则（本原型的设计约束）

    这是一面挂在沙龙工位前的独立壁挂镜，不是手机 App，也不是平板。顾客双手常拿着包或手机，且正在照镜子，因此交互以隔空手势为主、语音为辅、触控兜底——界面必须按「一米 UI」重做，而不是把 App 放大。

    镜面即界面

    中央默认保留实时镜面影像，试戴模型与建议以深色玻璃浮层挂在四周，不铺满整屏。

    隔空手势为主

    挥手换发型、左右挥换风格、上下挥调卷度、握拳收藏；全程无需触碰屏幕。

    一米可读

    正文基准 ≥24px（镜面画布），标题 42-58px，数字 92px+；触控目标高度 ≥66px。

    贴边竖向导航

    用左缘细长竖向模块栏替代手机底部 tab 栏；无状态栏、无刘海、无信号电量。

    中性灰判读区

    肤质检测与前后对比两屏强制切到中性灰底——任何界面色都会干扰肤色与发色的判读。

    入座即启动

    顾客坐下自动唤醒，并自动进入「检测 → 试戴」分支，不弹广告、不做前置引导。

    06显色与灯光：为什么必须是 7200K / Ra>90

    发色与肤色的判读高度依赖光源。沙龙工位顶灯多为暖光，会让冷色系发色显灰、暖棕显脏。本机以7200K 高显色补光（Ra>90）建立稳定的判读基准。

    场景光源典型色偏对发色 / 肤色的影响
    本机补光（基准）7200K · Ra>90接近日光的中性显色作为发色与肤色判读的基准条件
    沙龙工位顶灯暖光整体偏黄，暖色显饱和冷灰系显脏、暖棕显沉，需补光校正
    商场白光冷白 LED偏蓝，蓝色更艳、暖色发灰雾感色号更显冷，需提示顾客
    户外日光日光颜色最真实，正午偏冷作为「离店后真实呈现」的参照

    为什么检测用中性灰底

    界面上的任何品牌色都会与被测肤色发生同时对比效应，导致判读偏差。因此检测与对比两屏统一使用18% 中性灰背景。

    三档灯光模拟

    原型提供「工位暖光 / 商场白光 / 户外日光」三档切换，用于向顾客说明同一染膏在不同光源下的差异，降低「回家发现色不对」的退货率。

    07落地与风险提示

    灯光色偏

    各店工位灯光不一致。以 7200K 补光 + 中性灰底建立统一基准，并在方案卡中标注「离店后日光下的呈现」。

    肤质检测精度

    三光谱检测受妆容、油脂、角度影响。报告定位为趋势参考而非医学诊断，不做绝对化承诺，厚妆时提示「建议卸妆后复测」。

    隐私合规

    面部影像与肤质数据属敏感个人信息，须明示用途、本地处理、不上传原始影像，并提供一键清除。

    发型贴合度

    发际线与发量因人而异，2D 试戴需标注「示意效果」，正式操作前由发型师做发束实测确认。

    染膏与档期一致性

    色号库与排班需高频同步。低库存色号给出「仅剩 N 支」提示；档期被占用时即时刷新可选时段。

    评测呈现

    本原型以浏览器打开即可评审；摄像头仅在本机 localhost / https 下生效，本地文件直开时自动降级为模拟镜面。Chrome / Edge 为基准浏览器。
